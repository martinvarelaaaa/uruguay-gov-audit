Pipeline open-source que baja la data pública del Estado uruguayo, la indexa en tu máquina y la expone como MCP server — para que cualquier agente de IA pueda auditar con cifras citables.

open source · MIT 100% local checksum en todo

El registro de ingesta descargó ya 75 GB de datos públicos oficiales — compras del Estado desde 2002, datos abiertos de 70 organismos, parlamento, elecciones, transcripciones de canales oficiales. Cada archivo con su sha256 y URL de origen: lo podés verificar vos.

El índice

Todo lo descargado entra en un SQLite local (govaudit.sqlite3, 0,75 GB): una tabla compras de 2M+ contratos con índices por organismo y año, y un índice full-text (FTS5) de todas las transcripciones. Preguntas que antes eran imposibles —«¿qué compró el Ministerio de Salud después de que su ministro dijera X?»— se responden en milisegundos, con la URL oficial al pie.

Cómo se usa

El corazón es un MCP server (Model Context Protocol): lo enganchás a Claude Desktop, Hermes, o cualquier cliente MCP, y el agente tiene acceso a herramientas de pregunta dirigida:

  • compras_buscar — ¿qué compró el organismo X, quién le vendió, cuánto?
  • compras_gasto_proveedor — el historial completo de un proveedor del Estado
  • compras_estadisticas — totals anuales, top proveedores, top compradores
  • discursos_buscar — qué se dijo en sesión, con link al minuto exacto
  • parlamento_buscar — proyectos, repartidos, asistencias

Cada respuesta lleva provenance: nombre del dataset, URL oficial de origen y fecha de descarga. Si el dato no está, el bot lo dice — en vez de improvisar.

El registro de ingesta (lo que lo hace auditable)

Ningún dato "aparece": cada extracción —dataset, video, PDF, tweet— deja una fila en un ledger con sha256, URL original, timestamp y duración. El supervisor re-lanza lo fallido cada 30 minutos. El CSV runs/ledger.csv permite auditar el propio pipeline en Excel.
